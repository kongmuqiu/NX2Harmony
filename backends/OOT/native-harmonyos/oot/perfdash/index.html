⑤ 每个数是什么、从哪来 采集口径

数含义来源
GPU 忙碌占比GPU ms ÷ 帧 ms。GPU ms 是每个提交槽首尾两个 GPU 时间戳之差的合计，按 300 帧平均；帧 ms = 1000 ÷ fps。只算本游戏的提交，不含系统合成。运行日志 frame N, per frame: … GPU X ms 和 frame N: X fps over the last 300
每帧空闲帧 ms − GPU ms：一帧里 GPU 没在执行本游戏任何提交的时间。同上
逐帧精确 / 有活在手逐帧精确 = Σ 各槽 gpu= ÷ game_iv。有活在手 = 各槽从 QueueSubmit 返回到观察到完成这段时间的并集（上一帧拖进来的也算）÷ 帧间隔；完成时刻是“看到”的时刻，略晚于真正完成，所以它是忙的上界、空闲的下界。运行日志 [frame-tl late]（游戏带 TOTK_FRAME_TIMELINE=1 才有；同 frametl.py 的解析）
帧内时间线每帧一条：上排是回放线程各次回放的起止，细竖线是它封口一个槽的时刻；下排是 GPU——上一帧剩下的、本帧已提交未完成的、空闲的。底部是最近 300 帧里各时刻“GPU 空闲”“有回放记录”的帧占比。有些帧的长回放没有记在 walks= 里（上排空着而槽还在封口），这时回放在不在跑要看封口的竖线。[frame-tl late] 的 walks=、slots=（封口、QueueSubmit、完成、GPU ms）
gpuLoad、GPU 频率系统统计的 GPU 负载百分比和当前频率，一两秒一个采样（每次起一个 SP_daemon）。hdc shell "SP_daemon -N 1 -c -g" 的 gpuLoad、gpuFrequency
系统等级温控等级 1–6；GPU 负载等级 1–10：总负载、顶点、片元、纹理、带宽；应用读到的 GPU 频率。每 5 秒一行。hdc shell "hilog -x | grep 'device state'"（应用 NGGame，Game Service Kit）
一帧的拆分录制 = 回放线程录制命令的时间（不含等待）；等 GPU = 回放线程等提交槽的时间，细分为环槽 / 快照区 / 其它栅栏；其余 = 帧 ms − 录制 − 等 GPU，即游戏自己的逻辑和回放之外的一切。per frame: recording X ms, waiting for the GPU Y ms；waits/frame by kind: ring slot … uniform-snapshot arena … other fences …
回放线程每帧在 CPU 上的时间和离开 CPU 的时间（墙上时间 − CPU 时间）、每帧绘制数、每个绘制的 CPU 微秒。walker cpu frame N: cpu … wall … draws … offcpu …
提交槽每帧交给 GPU 的槽数；小槽 = 封口时不足 8 个绘制的槽；分块提交 = 一次游戏提交被拆开提前交出的次数；环的格数。slot submission/frame: all/game/handed …；slots sealed with fewer than 8 draws …, chunk submissions …; ring N
CPU 各核每个逻辑 CPU 的频率和负载。SP_daemon 单次采样的负载很粗（常见 0 / 25 / 50 / 100），表里显示的是最近 10 次的平均。SP_daemon 的 cpuNFrequency、cpuNUsage
线程所在核关键线程最近 10 秒落在各逻辑 CPU 上的采样占比（0.1 秒看一次）；role 2 是游戏主线程，role 1 是回放线程。运行日志 [ohos-pin] totk-walk … (role N) ran on cpu4:17% …
频率保持线程最近 30 秒空转 / 睡眠各多久。这一行里的 cpu 是物理核编号（核 7 = 逻辑 CPU 10–11）。运行日志 [ohos-spin] the last 30 s: spun … slept … on cpu N now
怎么取的运行日志：hdc file recv -b nx2h.u000000.oot /data/storage/el2/base/haps/entry/files/android/totk-native.log，每 5 秒一次，只解析新增部分；日志没有时间戳，窗口在时间轴上的位置按取到的时刻估计（±5 秒）。只采样，不锁频、不改手机上任何设置。
实时：python -I native-harmonyos\oot\perfdash\perfdash.py；离线回放：python -I native-harmonyos\oot\perfdash\perfdash.py --replay artifacts\runs\<日志> [--speed N] [--replay-sys <系统采样>]；实时加 --record 把系统采样存到 artifacts\runs\perfdash-sys-*.txt。
